# Contao Company Bundle

A foundation bundle that registers the `company` backend module group for child bundles like Clients, Projects, and Testimonials.

## Features

- Backend module group `company` with custom navigation icon
- Loads after the Contao core bundle

## Requirements

- PHP ^8.3
- Contao ^5.3

## Installation

```bash
composer require respinar/contao-company
```
